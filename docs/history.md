# 更新历史

本文件按功能落地日期记录面向使用者的行为变化。

## 2026-11-25

### CLI 与初始化

- 增加 `task <name> --init`、`task '*' --init` 和 `task '*geoip' --init`。
- 全量 `init` 和 `task '*' --init` 校验 `first-run: yes`。
- 初始化按列表批量清空静态和动态条目，再使用 RSC 全量导入。
- 增加 `--nocache`，重新获取数据并继续处理，支持独立 `init`。

### 同步、日志与发布

- 去掉本地 RouterOS 条目归属快照。RSC 按列表和地址现场匹配，REST 在修改或删除前重新查询。
- 普通源条目省略注释。白名单的不同备注按首次出现顺序合并，使用配置的注释前缀包裹。
- DEBUG 输出源记录数、原始白黑名单数、完全重复数、优化减少量和最终条数。
- 完成 Linux amd64 musl 静态 Release 构建，并补充快速开始和使用指南。

## 2026-11-24

### 首版功能

- 增加 YAML 配置校验、任务选择、启动检查与定时调度。
- 支持 TXT、共享 GeoIP DAT、本地文件和远程候选源，以及 ETag、BLAKE3 和工作目录快照。
- 支持 RouterOS IPv4/IPv6 列表的 REST 更新、SFTP/SSH RSC 导入、节点选择和读回核验。
- 增加白黑名单、CIDR 合并、记录数上下限和 50% 默认变动阈值。
- 增加 Live API，向允许的 RouterOS 列表转发临时主机地址。
